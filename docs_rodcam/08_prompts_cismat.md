Bitácora del uso de IA

Durante la elaboración del análisis del caso de ciberataque a BancoEstado, se utilizó inteligencia artificial como herramienta de apoyo para organizar información, estructurar contenidos jurídicos y apoyar la redacción técnica.

1. Prompts utilizados
Prompt 1: Búsqueda general del caso

Objetivo: obtener contexto inicial del incidente.

“Explícame un caso de hackeo de ciberseguridad ocurrido en Chile, incluyendo qué pasó, cuándo ocurrió y cuál fue su impacto.”

Resultado:
Se identificó el caso del ataque de ransomware a BancoEstado como referencia principal.

Prompt 2: Resumen ejecutivo

Objetivo: sintetizar los hechos principales.

“Realiza un resumen ejecutivo del caso BancoEstado indicando qué pasó, cuándo ocurrió, quiénes participaron y cuál fue el impacto.”

Corrección realizada:
Se ajustó la redacción para mayor precisión jurídica y formalidad académica.

Prompt 3: Marco normativo

Objetivo: identificar legislación aplicable.

“Indica las leyes y regulaciones nacionales e internacionales aplicables al caso BancoEstado, justificando cada norma.”

Corrección realizada:
Se reorganizó la información separando normas penales, de protección de datos y regulatorias.

Prompt 4: Tipificación penal

Objetivo: relacionar conductas con delitos.

“Mapea las acciones del atacante con los artículos de la Ley 21.459.”

Corrección realizada:
Se verificó coherencia entre la conducta descrita y el artículo citado.

Prompt 5: Protección de datos

Objetivo: aplicar normativa de datos personales.

“Explica el tratamiento de datos según la Ley 19.628, diferenciando datos personales, sensibles y derechos ARCO.”

Corrección realizada:
Se incorporaron ejemplos concretos vinculados al ámbito bancario.

Prompt 6: Recomendaciones finales

Objetivo: formular propuestas preventivas.

“Elabora recomendaciones de seguridad y una reflexión final del análisis.”

Corrección realizada:
Se reforzó el enfoque técnico-jurídico.

2. Correcciones y ajustes realizados

Durante el proceso fue necesario realizar correcciones para mejorar:

Precisión normativa

Se revisó la correspondencia entre artículos legales y conductas del caso.

Contextualización jurídica

Se adaptó la explicación legal específicamente al contexto chileno.

Formalidad académica

Se modificó lenguaje explicativo por redacción técnica más apropiada para informe.

Orden lógico

Se reestructuró el contenido para seguir una secuencia:

Hechos
Normativa
Tipificación
Responsabilidades
Protección de datos
Recomendaciones
3. Reflexión sobre el uso de IA

El uso de inteligencia artificial permitió:

Ventajas
Agilizar la búsqueda y organización de información
Facilitar la estructuración del análisis
Identificar normas jurídicas relevantes
Mejorar claridad expositiva
Limitaciones
La información entregada requiere verificación jurídica
Algunas referencias legales deben contrastarse con fuentes oficiales
La IA puede simplificar excesivamente aspectos técnicos o normativos
Aprendizaje obtenido

La experiencia demuestra que la IA debe utilizarse como herramienta de apoyo y no como fuente única de validación.

Su valor principal está en:

Sistematizar información
Orientar el análisis
Facilitar redacción preliminar

Pero el juicio crítico y la revisión humana siguen siendo esenciales para garantizar rigor académico.
